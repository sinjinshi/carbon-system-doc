```txt

app/api
只做 HTTP 适配：解析 request、zod 校验、鉴权、调用 service、返回 response。

service/*/schemas
放 zod schema，给 API Route 和页面表单共同复用。这里不能 import prisma、redis、fs、server-only。

service/*/server
放服务端业务代码：service、repository、mapper、vo。这里不能被 Client Component 引入。


apps/admin/components
放 admin 内部公共组件。

packages/ui
放 admin、merchant 都能复用的纯 UI 组件，不写业务逻辑。

packages/auth / db / logger / shared
放跨应用共享能力。

```

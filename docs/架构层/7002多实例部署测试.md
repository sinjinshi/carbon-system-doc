# 多实例部署测试



你的 Render + Next.js 多实例生产环境，直接按这个标准做：

NEXT_SERVER_ACTIONS_ENCRYPTION_KEY=Dp5Lmn89lj1H5vWMTBYPHKpolJEshkbi0Y65ZZnb0ak=


> openssl rand -base64 32

固定的base64 32字节密钥

同时加上：

// next.config.js
const nextConfig = {
  generateBuildId: async () => {
    return process.env.RENDER_GIT_COMMIT || 'local';
  },
};

module.exports = nextConfig;

NEXT_SERVER_ACTIONS_ENCRYPTION_KEY 负责 Server Action 一致性，generateBuildId 负责多实例/滚动部署时构建版本一致性。


## 测试清单

| 测试项                 | 目标                                  |
| ---------------------- | ------------------------------------- |
| 页面首次打开           | 是否有 hydration error                |
| 页面刷新 30 次         | 多实例下是否偶发水合问题              |
| 点击左侧菜单           | layout + 子路由切换是否稳定           |
| 子路由刷新             | 菜单选中状态是否稳定                  |
| API 实例显示           | SSR 实例和 API 实例是否可能不同       |
| memory-counter         | 证明内存不能共享                      |
| Server Action 连续点击 | 检查加密 key / action 跨实例问题      |
| Render 日志            | 是否有 `Failed to find Server Action` |
| 浏览器 Console         | 是否有 hydration mismatch             |
| Trace / Video          | 定位偶发问题发生在哪一步              |
